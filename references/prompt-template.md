# 图像编辑提示词模板

查看原照片及所选内置参考图后，替换全部花括号。输入图1是原照片编辑目标，输入图2及其后是纯风格参考；在提示词中明确这些角色。按用户指定覆盖默认比例与数量。

```text
图1为原照片编辑目标，图2及后续图片仅为布局与笔触参考。制作一张3:4竖版摄影与微型线稿故事作品，严格匹配正向参考的安静留白风格，不套用旅游宣传海报。不要复制参考图的具体主体。

上方约60%—70%保留原照片真实摄影质感，保持{主体、人物、建筑、光线、色彩、空间关系、关键辨识部位}。只允许必要等比例缩放和裁切，不拉伸、不改造建筑、不重画人物、不新增真实场景。

下方为暖白象牙纸面、极轻纸张纹理和大量留白。纸面沿{实际景物边缘}自然进入，可斜向、曲线或局部穿插；不把60%—70%做成强制水平切线，不做厚重撕纸拼贴，不把照片当成中央窗口，不在四周补画满版景物。

选择原照片真实存在的{唯一元素}，从{明确起点}沿{方向和透视}顺势接入纸面。先减少真实纹理，再简化为{少量轮廓线}。位置、方向、尺度、透视连贯。不在纸面复刻完整背景。{小人保持黑线；如有必要，仅在延伸景物上保留局部原图淡彩或纹样，逐渐消退，不添加装饰色块。}

只加入一个黑色钢笔线稿人物，高度约整图7%—10%，位于{位置}，正在{简单动作}。合理支撑：{手、脚、臀部或道具的接触点及受力关系}。自然人体比例，无清晰五官，服装道具简化，细而略不规则的松弛笔触。

只添加一句小而克制的英文手写旁白，准确写为“{1—5个英文单词}”，置于{不遮挡支撑点的留白位置}，与动作呼应。

整体诗意、简洁、有编辑感。不要悬浮小人、巨大人物、复杂五官、动漫风格、密集排线、完整背景复刻、额外人物、网格、边框、新增水印、大中文地名、书法大标题、英文副标题、坐标、地图路线、定位点、指南针、日历、邮票、装饰笔刷、飞溅水彩或满版建筑速写。保留原照片，输出新图。
```
